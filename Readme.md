A textbook on [the Micron programming language](https://github.com/micron-language/specification/) is being written here.

The book is for readers who already program in another language, such as C, Go, (Free)Pascal, and Oberon. It does not intend to teach programming; it shows how each language feature of Micron is used, why it is designed the way it is, and how the habits of the arrival language translate. 

There will be a lot of examples in the book which compile and run with [the Micron micc compiler/interpreter](https://github.com/rochus-keller/micron/).

Planned content:

- why Micron exists, a tour of the language and toolchain, notation, types and values, and a chapter for arrivals from C, Pascal and Go
- program structure and modules, structured types, abstraction without OOP, objects and interfaces, generic modules, dynamic memory, compile-time and low-level programming, C interoperability, and error handling
- a complete single-language operating system, from the machine and build process through kernel, files and modules, display, viewers, texts and editor, up to graphics applications.

The text is published incrementally, as the chapters are written/reviewed.

Comments, corrections and questions are welcome; please use the issue tracker.
